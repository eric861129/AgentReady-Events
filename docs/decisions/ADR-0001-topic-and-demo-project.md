
# ADR-0001：選擇 WebMCP 與活動報名平台作為鐵人賽主題

## 狀態

Accepted

## 日期

2026-06-24

## 背景

2026 iThome 鐵人賽需要一個可以連續拆分成 30 天文章的技術主題。

主題需要同時具備：

- 新穎性
- 實作性
- 大眾理解度
- 技術深度
- 最終展示成果

AI Agent 與 Web 的互動正在快速發展。傳統網站主要設計給人類操作，但 AI Agent 若要操作網站，往往需要透過畫面理解、DOM 分析或模擬點擊完成任務。

WebMCP 提供了一個新的方向：網站可以主動公開結構化工具，讓 AI Agent 更穩定地理解與呼叫網站功能。

## 決策

本系列選擇以下題目：

《網站不只給人用：30 天打造 AI Agent 看得懂的 WebMCP 網站》

實作專案選擇：

AgentReady Events：AI Agent 友善的活動探索與報名平台

## 理由

選擇 WebMCP 的原因：

1. 題目新穎，具備技術辨識度
2. 適合與 AI Agent、Web 標準、前端工程、安全設計結合
3. 可以拆成 30 天連續實作
4. 最後能形成完整可展示作品
5. 不只是工具介紹，而是可以討論未來網站設計方式

選擇活動報名平台的原因：

1. 大眾容易理解
2. 使用者旅程完整
3. 可自然涵蓋搜尋、收藏、報名、取消等操作
4. 可清楚區分唯讀、低風險、中風險與高風險操作
5. 不需要處理真實金流與複雜後台

## 取捨

本系列不追求打造完整商業活動平台，而是聚焦在 Agent-ready Web 的設計與實作。

因此將排除：

- 真實付款
- 大型管理後台
- 完整會員中心
- 複雜推薦系統
- 真實寄信服務

## 結果

本決策將作為後續架構圖、Tool Catalog、技術來源清單與 30 天文章規劃的基礎。
