
# Project Brief：AgentReady Events

## 專案名稱

AgentReady Events

## 系列名稱

《網站不只給人用：30 天打造 AI Agent 看得懂的 WebMCP 網站》

## 副標題

從 Agentic Web、結構化工具、Human-in-the-loop，到安全與 Evals 的完整實戰

## 專案定位

AgentReady Events 是一個活動探索與報名平台。

本專案的重點不是打造完整商業活動平台，而是示範一個傳統網站如何逐步變成 AI Agent 友善網站。

## 核心問題

目前多數 AI Agent 操作網站時，需要依賴畫面理解、DOM 分析與模擬點擊。

這種方式容易受到 UI 改版、按鈕文字變更、DOM 結構調整與流程變動影響。

本專案將探索另一種方式：

讓網站主動公開結構化工具，使 AI Agent 能夠理解網站提供哪些功能、需要哪些參數，以及操作後會得到什麼結果。

## 核心使用者旅程

1. 使用者請 Agent 搜尋活動
2. Agent 使用網站公開的搜尋工具取得結果
3. 使用者請 Agent 查看活動詳情
4. 使用者請 Agent 收藏活動
5. 使用者請 Agent 協助填寫報名資料
6. 使用者檢查資料後自行確認送出
7. 使用者請 Agent 查看自己的報名紀錄
8. 使用者確認後取消指定報名

## MVP 範圍

本專案會實作：

- 活動列表
- 活動搜尋
- 活動篩選
- 活動詳情
- 收藏活動
- 活動報名
- 我的報名
- 取消報名
- Agent Debug Panel
- WebMCP Tools
- 權限與確認流程
- 基礎測試與 Evals

## 非目標

本專案不實作：

- 真實金流
- 真實票券系統
- 大型管理後台
- 複雜會員系統
- 真實寄信服務
- 第三方 OAuth
- 商業級多租戶架構

## 成功標準

Day 30 時，本專案應該能展示：

- 人類使用者可以正常操作網站
- AI Agent 可以透過 WebMCP Tools 理解並操作部分網站功能
- 高風險操作需要使用者確認
- 後端仍會檢查登入與權限
- 專案具備基本測試與 Agent Eval Dataset
